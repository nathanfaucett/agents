# Reproducibility and Versioning

- Keep prompts and prompt builders in source control and change them through code review.
- Pin a specific production model snapshot when reproducibility matters.
- Maintain representative fixtures, tests, and evaluation suites for prompt behavior.
- Version and deploy prompt changes with the application; use feature flags or configuration for staged rollouts.
- When this guidance is also packaged as an agent skill, version the skill independently of the API prompt.
